# WaveForge

**A Desktop Audio Editor Built with C++, Qt 6, and CMake**

WaveForge is a Windows desktop audio editor developed using Qt Widgets and C++17. The project demonstrates reusable custom widgets, WAV audio processing, waveform visualization, audio editing, playback, and undo/redo functionality.

## 1. Features

- Open and save WAV audio files.
- Display audio waveforms and a timeline ruler.
- Play, pause, stop, and seek through audio.
- Select audio regions using waveform selection handles and a range slider.
- Trim and cut selected audio.
- Apply gain from 0% to 200%.
- Apply linear fade-in and fade-out effects.
- Undo and redo editing operations.
- Export edited audio as WAV.
- Zoom and horizontally scroll through the waveform.
- Display an audio level meter.
- Switch between dark and light themes.
- Use reusable, custom-painted Qt widgets.

## 3. Prerequisites

Install the following software before building WaveForge on a new computer.

### 3.1 Visual Studio

Install Visual Studio with the **Desktop development with C++** workload.

The installation must include:

- MSVC C++ compiler.
- Windows SDK.
- CMake tools for Windows.
- MSBuild.

The current development environment uses Visual Studio 2026 with the MSVC 2022-compatible Qt kit.

### 3.2 Qt

Install Qt 6 with the following kit and modules:

- Qt 6.12.0 MSVC 2022 64-bit.
- Qt Multimedia.
- Qt Concurrent, included with Qt Core in the standard Qt installation.

The current Qt installation is:

`D:\Softwares\Qt\6.12.0\msvc2022_64`

**Important:** The path above is specific to the current development computer. On another computer, install a compatible Qt 6 MSVC kit and use its actual installation path.

Do not use a MinGW Qt kit with an MSVC build.

### 3.3 CMake

Install CMake if it is not already available through Visual Studio.

Verify the installation from Developer PowerShell:

```powershell
cmake --version
```

Verify the C++ compiler:

```powershell
cl
```

Run these commands in **Developer PowerShell for Visual Studio**.

## 5. First-Time Setup on Windows

### Step 1: Get the project

Clone the repository or download its source code.

If Git is installed:

```powershell
git clone <YOUR_REPOSITORY_URL>
cd WaveForge
```

Replace `<YOUR_REPOSITORY_URL>` with the actual repository URL.

Alternatively, extract the project into a directory such as:

`D:\Projects\WaveForge`

### Step 2: Configure the Qt installation

Open **Developer PowerShell for Visual Studio**.

If the supplied `scripts\setup.bat` script detects your Qt installation, run it from Command Prompt:

```bat
cd /d D:\Projects\WaveForge
scripts\setup.bat
```

The script searches common Qt installation directories for a compatible MSVC 2022 kit.

If the script does not find Qt, configure the environment variable manually in PowerShell:

```powershell
$env:WAVELINE_QT_ROOT = "D:\Softwares\Qt\6.12.0\msvc2022_64"
```

This sets the variable for the current PowerShell session.

To configure it persistently for future terminals, use:

```powershell
[Environment]::SetEnvironmentVariable(
    "WAVELINE_QT_ROOT",
    "D:\Softwares\Qt\6.12.0\msvc2022_64",
    "User"
)
```

Open a new terminal after setting the persistent variable.

If your Qt installation is in another directory, replace the example path with the correct one.

### Step 3: Configure the project

From Developer PowerShell, navigate to the project directory:

```powershell
cd D:\Projects\WaveForge
```

Configure the project using CMake:

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64 -DCMAKE_PREFIX_PATH="D:\Softwares\Qt\6.12.0\msvc2022_64"
```

This creates the build directory and generates the Visual Studio project files.

If you use a different Visual Studio version, select a CMake generator installed on that computer. You can list available generators with:

```powershell
cmake --help
```

### Step 4: Build WaveForge

Run:

```powershell
cmake --build build --config Debug
```

For a Release build:

```powershell
cmake --build build --config Release
```

If the build succeeds, the executable will normally be located at:

```text
build/Debug/WaveForge.exe
```

or:

```text
build/Release/WaveForge.exe
```

## 7. Open WaveForge in Visual Studio

1. Start Visual Studio.
2. Select **Open a Local Folder**.
3. Select the WaveForge root directory containing `CMakeLists.txt`.
4. Wait for CMake configuration to complete.
5. Select the appropriate Debug or Release configuration.
6. Build the project.
7. Run `WaveForge.exe`.

This is a CMake folder-based project; a separate `.sln` file is not required.

When adding new source files, create them physically under `src/app`, `src/core`, or `src/widgets`. CMake will discover them through the existing recursive source configuration.

If a new file does not appear, use Visual Studio's CMake reconfiguration or delete the CMake cache and reconfigure the project.

## 8. Deploy the Application

A successful build does not necessarily mean the executable can run on another computer without Qt installed.

For a Debug build, deploy the required Qt libraries using the Qt deployment utility:

```powershell
& "D:\Softwares\Qt\6.12.0\msvc2022_64\bin\windeployqt.exe" --debug --compiler-runtime "D:\Projects\WaveForge\build\Debug\WaveForge.exe"
```

For a Release build:

```powershell
& "D:\Softwares\Qt\6.12.0\msvc2022_64\bin\windeployqt.exe" --release --compiler-runtime "D:\Projects\WaveForge\build\Release\WaveForge.exe"
```

Adjust the Qt and executable paths to match your computer.

Test the deployed application on a computer that does not have the development environment installed before distributing it. Follow the applicable Qt licensing requirements when distributing Qt libraries.

## 9. Troubleshooting

### CMake cannot find Qt6

Typical errors include:

```text
Could not find a package configuration file provided by Qt6
Qt6Config.cmake was not found
```

Check that the Qt MSVC kit exists and that `CMAKE_PREFIX_PATH` points to its root directory.

Example:

```text
D:\Softwares\Qt\6.12.0\msvc2022_64
```

Reconfigure CMake after correcting the path.

### Qt compiler compatibility errors

Make sure that the compiler and Qt kit are compatible.

Use the MSVC 2022 64-bit Qt kit for the current MSVC build. Do not mix MSVC and MinGW libraries.

### Qt DLLs are missing when launching

Deploy the application with `windeployqt`, or run it in an environment where the correct Qt libraries are available.

### New source files are not detected

Confirm that the files are under `src/` and that their extensions are `.h` and `.cpp`.

Then reconfigure CMake and rebuild.

### Build errors after changing headers

Try rebuilding the project:

```powershell
cmake --build build --config Debug
```

If generated files or the CMake configuration are stale, close Visual Studio, remove the generated `build/` directory, and repeat the configuration and build steps.

Do not delete the source files or the repository's `CMakeLists.txt`.

### The application builds but does not play audio

Check that the WAV file opens successfully, that the Windows audio output device is available, and that Qt Multimedia is installed and deployed correctly.


## 10. Current Development Scope

WaveForge focuses on single-track WAV editing. Multi-track editing, video editing, VST hosting, and audio recording are outside the initial scope.

Before a release, verify opening, playback, seeking, selection, editing, gain, fades, undo/redo, export, zoom, scrolling, theme switching, and behavior with longer audio files.
